# Team Assignment: Agentic AI System Development

## Overview

In this team assignment, you will work together to develop an **agentic AI system** that solves a real-world problem. This project will give you hands-on experience building, implementing, and evaluating an AI agent using the concepts and techniques covered in the course.

## Objectives

- Design and implement an agentic AI system that addresses a real-world problem
- Apply theoretical concepts (autonomy, social ability, reactiveness, proactiveness) in practice
- Gain experience with modern AI agent frameworks (e.g., LangChain, LangGraph)
- Collaborate effectively using version control and best practices
- Document your work comprehensively in a technical report

## Requirements

### 1. Project Scope

Your team must develop an agentic AI system that:

- Solves a **real-world problem** (not just a toy example)
- Demonstrates clear agentic characteristics (autonomy, social ability, reactiveness, and/or proactiveness)
- Uses appropriate tools and memory mechanisms
- Has well-defined objectives and success criteria

### 2. Repository Setup

- **Create your own Git repository** for this project
- You may **fork or clone** this course repository as a starting point
- Each team member must work in the **same shared repository**
- Use a platform like GitHub, GitLab, or Bitbucket to host your repository

### 3. Individual Contributions

**Critical Requirement:** Each student must:

- Use **their own Git account** (not a shared account) to contribute
- Make **individual commits** to both code and documentation
- Ensure their contributions are **traceable** through Git history
- Contribute meaningfully to both:
  - **Code implementation** (agent development, tools, memory, etc.)
  - **Final report** (writing sections, editing, reviewing)

### 4. Final Submission

For the final submission, you must provide:

1. **Complete Git repository** with full history

   - The repository must contain the entire Git history
   - Individual contributions must be clearly visible through commit history
   - Each commit should be properly attributed to the correct author
   - Include a `.git` folder or provide access to the remote repository

2. **Final report** (use the template in `report.md`)

   - The template can be changed if it makes sense. It serves as an orientation
   - Include an "Individual Contribution Log" section that summarizes each team member's contributions
   - The Git history will be cross-referenced with this log

3. **Working code**
   - All code should be functional and well-documented
   - Include a README with setup instructions
   - Provide example usage or a demo

## Best Practices

### Git Workflow

- Use **meaningful commit messages** that describe what was changed
- Make **frequent commits** (don't wait until the end to commit)
- Use **branches** for features or experiments, then merge via pull requests
- **Never** commit as another person or use a shared account
- Ensure your Git configuration has your correct name and email:
  ```bash
  git config user.name "Your Name"
  git config user.email "your.email@example.com"
  ```

### Collaboration

- Communicate regularly with your team
- Divide work clearly but collaborate on integration
- Review each other's code through pull requests
- Test the system together before final submission

### Code Quality

- Write clean, readable, and well-commented code
- Follow Python best practices (PEP 8)
- Include docstrings for functions and classes
- Organize your code into logical modules

## Evaluation Criteria

Your project will be evaluated based on:

1. **Technical Implementation**

   - Quality and functionality of the agentic system
   - Appropriate use of tools, memory, and frameworks
   - Code quality and organization

2. **Documentation & Report**

   - Completeness and clarity of the report
   - Quality of explanations and analysis
   - Connection between theory and implementation
   - Clear explanation of agentic characteristics in your system
   - Critical analysis of your agent's behavior

3. **Collaboration & Individual Contributions**

   - Evidence of meaningful individual contributions
   - Traceability through Git history
   - Team collaboration effectiveness

4. **Final Presentation**

   - Professional presentation of your agentic system
   - Ability to answer questions on your contributions to the project

## Important Notes

- **Start early**: Building a good agentic system takes time
- **Test thoroughly**: Your agent should work reliably, not just in one scenario
- **Document as you go**: Don't wait until the end to write the report
- **Be honest**: If something didn't work, explain why in your report
- **Individual accountability**: Each team member is responsible for their own contributions being visible in Git history

## Getting Started

1. Choose a problem to solve
2. Set up your Git repository (fork/clone this project or create a new one)
3. Configure Git with your personal account credentials
4. Create an initial project structure
5. Begin development and make regular commits
6. Start documenting your work early
